# `public/` contents

This folder is copied verbatim into `dist/` by Vite.

When you publish a Toy, the Bilibili Toy platform expects:

| File                         | Purpose                                            |
| ---------------------------- | -------------------------------------------------- |
| `favicon.svg`                | Browser tab icon.                                  |
| `cover.png` (or `cover.jpg`) | Toy card thumbnail. Suggested 16:9, ≥ 1280×720.    |
| `icon.png`                   | Square icon for the Toy picker. 256×256 or larger. |

Replace the placeholders before publishing — `toy create` will warn but not fail.
